# Пункт 5 — демонстрация DES

Из каталога `lab1`:

```powershell
go run ./point_5/cmd/des_demo
```

Пример проверяет все режимы: ECB, CBC, PCBC, CFB, OFB, CTR, Random Delta.
Для каждого режима проверяются 8 воспроизводимых псевдослучайных массивов длиной 0, 1, 7, 8, 9, 31, 64, 1025 байт со всеми четырьмя набивками.

Автоматически создаются небольшие файлы: текст UTF-8, PNG, WAV с тоном, видео YUV4MPEG2 (`.y4m`, два кадра), исходный код Go-теста и бинарный файл с концевыми нулями. Каждый файл шифруется и дешифруется во всех режимах с ANSI X.923, PKCS7 и ISO 10126. Применяются асинхронные методы контекста; число обработчиков — 4. Восстановленные данные сравниваются с оригиналом побайтово. Любая ошибка завершает программу с ненулевым кодом.

Свои файлы можно передать аргументами, в том числе музыку, видео и исходники тестов аллокатора:

```powershell
go run ./point_5/cmd/des_demo -out ./demo_output "D:\files\music.mp3" "D:\files\movie.mp4" "D:\files\allocator_test.cpp"
```

Каждый запуск создаёт отдельный каталог `demo_output/des-demo-*`; его путь выводится в конце. В `inputs` лежат автоматически созданные образцы. В `<режим>/<набивка>` находятся `.des` и `.restored`. Для каждого сообщения создаётся новый контекст со случайным IV; шифрование и дешифрование выполняются в одном запуске с тем же контекстом. Параметры отдельно не сохраняются.

Набивка Zeros удаляет все концевые нулевые байты, поэтому проверяется на массивах с ненулевым последним байтом. Для файлов, в том числе содержащих концевые нули, используются три остальные набивки. Контекст из пункта 2 загружает файлы целиком в память.

Проверка из `lab1`:

```powershell
go test ./...
go vet ./...
```

`TestDemo` проверяет все сочетания режимов и набивок, файлы с концевыми нулями и неизменность исходного файла. `TestDemoCancelled` проверяет отмену операции. Отдельных тестов промежуточных значений DES в этом пакете нет.

Демонстрация DEAL в пункте 7 использует общий сценарий `RunWithCipher` из этого пакета: меняются фабрика шифра, ключ, размер блока и расширение шифротекста. Прежний вызов `Run` и команда `des_demo` по-прежнему используют DES.
