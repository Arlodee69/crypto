# Пункт 7 — демонстрация DEAL

Из каталога `lab1`:

```powershell
go run ./point_7/cmd/deal_demo
```

По умолчанию используется DEAL-128 с демонстрационным ключом `0123456789abcdef` (16 ASCII-байтов). Первая строка показывает алгоритм, длину ключа и размер блока.

## Что программа проверяет

```text
main → RunWithKey → общая демонстрация из пункта 5
  → создать образцы файлов и псевдослучайные массивы
  → для каждого режима и набивки:
      новый DEAL + новый CipherContext со своим IV
      → зашифровать → расшифровать → сравнить каждый байт
      → вывести OK
```

- 7 режимов: ECB, CBC, PCBC, CFB, OFB, CTR, Random Delta.
- 4 набивки и 8 массивов длиной 0, 1, 15, 16, 17, 31, 64, 1025 байт: всего 224 проверки восстановления.
- 6 файлов: UTF-8 текст, PNG, WAV, видео Y4M, исходник Go, бинарный файл с конечными нулями.
- Файлы проверяются с ANSI X.923, PKCS7 и ISO 10126: 126 проверок. Zeros для файлов пропускается, поскольку удаляет настоящие конечные нули.

Вызовы асинхронные; демонстрация ожидает результат каждого вызова через канал. Внутри подходящих режимов блоки распределяются между четырьмя работниками.

Свой файл можно добавить аргументом:

```powershell
go run ./point_7/cmd/deal_demo "D:\files\example.txt"
```

Выбор DEAL-192 или DEAL-256 через hex-ключ (48 или 64 hex-цифры соответственно):

```powershell
go run ./point_7/cmd/deal_demo -key 000102030405060708090a0b0c0d0e0f1011121314151617
go run ./point_7/cmd/deal_demo -key 000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f
```

## Что показать преподавателю

1. В [demo.go](demo.go) показать подключение DEAL к существующему контексту и общей демонстрации.
2. В [../point_5/demo.go](../point_5/demo.go) показать цепочку `Encrypt → Decrypt → bytes.Equal`.
3. Запустить команду и объяснить: `CBC/PKCS7: 8 массивов — OK` означает точное восстановление всех восьми массивов.
4. Открыть каталог, напечатанный после `Результаты:`. Сравнить `inputs/text.txt` и `CBC/PKCS7/00-text.txt.restored`.

Каждый запуск создаёт `demo_output/deal-demo-*`. В каталогах `<режим>/<набивка>`:

| Файл | Содержимое |
|---|---|
| `*.deal` | Шифротекст |
| `*.restored` | Восстановленный оригинал |

Шифрование и дешифрование выполняются в одном запуске с тем же контекстом; параметры отдельно не сохраняются. Файлы загружаются в память целиком, поэтому для показа удобны небольшие файлы.

## Автоматическая проверка

```powershell
go test ./point_7 -v -count=1
```

`TestDEALDemo` выполняет демонстрацию для всех трёх длин ключа и проверяет неизменность исходного файла. `TestDEALDemoCancelled` проверяет отмену.
